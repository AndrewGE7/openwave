# Contributing

OpenWave welcomes focused improvements to the browser application, documentation, accessibility, and testing.

1. Open an issue describing the change and its user impact.
2. Keep the static web build dependency-free unless a dependency is clearly necessary.
3. Do not add medical, therapeutic, protective, or guaranteed-outcome claims.
4. Keep audio-generation changes conservative and preserve low-volume safety guidance.
5. Test in at least two current browsers and describe the result in the pull request.

Security or privacy concerns should not be posted with sensitive details in a public issue. Use the repository's private vulnerability-reporting channel when it is enabled.
